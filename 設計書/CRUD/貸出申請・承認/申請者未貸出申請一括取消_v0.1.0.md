| メソッド物理名 | cancel_pending_by_requester |

### 処理概要

#### 【目的】
- 申請者を指定して、未貸出の申請（申請中・承認済み）をすべて取消へ更新する。

#### 【処理概略】
- 該当する申請を内部IDの昇順で行ロックして取得し、取消（システム取消）へ更新して`flush`する（`commit`は呼び出し元が行う）。
- ユーザー編集（設計（認証・ユーザー管理））で、ユーザー無効化に伴う自動取消に利用される。

## ○処理詳細

### 1. 対象の貸出申請の取得

- (1) loan_requestテーブルから、対象を行ロックして取得する。

  ```sql
  SELECT * FROM loan_request
  WHERE requester_id = :requester_id
    AND status IN ('requested', 'approved')
  ORDER BY id ASC
  FOR UPDATE;
  ```

  | 区分 | 項目名 | 設定値・設定元 | 備考 |
  |---|---|---|---|
  | 条件 | 申請者（ユーザー内部ID） | 入力値．申請者内部ID | - |
  | 条件 | 状態 | `requested`・`approved` | 設計書「テーブル定義（models）」の列挙値（申請状態）を参照 |
  | 並び順 | 内部ID | 昇順 | ロック取得順を固定し、他の処理とのデッドロックを避ける |

### 2. 貸出申請の更新

- (1) 1．(1)の各貸出申請について、以下のフィールドを更新し、`flush`する。

  | 論理名 | 設定値 | 備考 |
  |---|---|---|
  | 状態 | `canceled` | 設計書「テーブル定義（models）」の列挙値（申請状態）を参照 |
  | 取消した者（ユーザー内部ID） | NULL | システムによる取消のため空 |
  | 取消日時 | 入力値．現在日時 | - |
  | 却下・取消理由 | 入力値．理由 | - |
