| メソッド物理名 | get_loan_request_by_id |

### 処理概要

#### 【目的】
- 内部IDを指定して貸出申請を1件取得する。

#### 【処理概略】
- loan_requestテーブルから内部IDが一致するレコードを取得する。
- 申請取消・承認・却下・管理者取消の各処理から利用される。

## ○処理詳細

### 1. 貸出申請取得

- (1) loan_requestテーブルから取得する。

  ```sql
  SELECT * FROM loan_request
  WHERE id = :loan_request_id
  -- 入力値．行ロック要否がTrueの場合のみ FOR UPDATE を付与する
  ;
  ```

  | 区分 | 項目名 | 設定値・設定元 | 備考 |
