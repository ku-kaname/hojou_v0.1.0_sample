### 処理概要

#### 【目的】
- ユーザーのトークン世代を+1し、発行済みトークンを失効させる（ログアウト・無効化・ロール変更）。

#### 【処理概略】
- トークン世代と更新日時のみを更新する。

## ○処理詳細

### 1. トークン世代更新

- (1) app_userテーブルを更新する。

  ```sql
  UPDATE app_user SET
    token_generation = token_generation + 1,
    updated_at = :now
  WHERE id = :user_id;
  ```
