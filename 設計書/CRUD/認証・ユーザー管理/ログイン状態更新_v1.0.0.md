| メソッド物理名 | update_login_state |

### 処理概要

#### 【目的】
- ログインの成功・失敗に応じて、連続認証失敗回数とロック解除日時を更新する（F01）。

#### 【処理概略】
- 呼び出し元が算出した値をそのまま設定する（ロックの判断は持たない）。

## ○処理詳細

### 1. ログイン状態更新

- (1) app_userテーブルを更新する。

  ```sql
  UPDATE app_user SET
    failed_login_count = :failed_login_count,
    locked_until = :locked_until,
    updated_at = :now
  WHERE id = :user_id;
  ```

  | 区分 | 項目名 | 設定値・設定元 | 備考 |
  |---|---|---|---|
  | 更新内容 | 連続認証失敗回数 | 入力値．連続認証失敗回数 | - |
