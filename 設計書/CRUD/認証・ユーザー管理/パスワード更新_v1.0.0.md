| メソッド物理名 | update_password |

### 処理概要

#### 【目的】
- ユーザーのパスワードハッシュを更新し、発行済みトークンを失効させる（F02・F16）。

#### 【処理概略】
- パスワードハッシュ・初回パスワード変更要否を更新し、トークン世代を+1し、認証失敗状態を初期化する。

## ○処理詳細

### 1. パスワード更新

- (1) app_userテーブルを更新する。

  ```sql
  UPDATE app_user SET
    password_hash = :password_hash,
    must_change_password = :must_change_password,
    token_generation = token_generation + 1,
    failed_login_count = 0,
    locked_until = NULL,
    updated_at = :now
  WHERE id = :user_id;
  ```

  | 区分 | 項目名 | 設定値・設定元 | 備考 |
  |---|---|---|---|
  | 更新内容 | パスワードハッシュ | 入力値．ハッシュ済みパスワード | - |
  | 更新内容 | 初回パスワード変更要否 | 入力値．初回パスワード変更要否 | - |
  | 更新内容 | トークン世代 | 現在値＋1 | 発行済みトークンを失効させる |
  | 更新内容 | 連続認証失敗回数 | 0 | - |
  | 更新内容 | ロック解除日時 | NULL | - |
  | 更新内容 | 更新日時 | 入力値．現在日時 | - |
  | 条件 | 内部ID | 入力値．ユーザー情報．内部ID | - |
