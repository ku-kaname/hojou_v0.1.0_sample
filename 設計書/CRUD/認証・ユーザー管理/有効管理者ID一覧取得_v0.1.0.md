## ○処理詳細

### 1. 有効管理者取得

- (1) app_userテーブルから取得する。

  ```sql
  SELECT id FROM app_user
  WHERE role = 'admin' AND is_active = TRUE
  ORDER BY id ASC;
  ```

  | 区分 | 項目名 | 設定値・設定元 | 備考 |
  |---|---|---|---|
  | 条件 | ロール | 管理者（`admin`） | 列挙値は設計書「テーブル定義（models）」を参照 |
  | 条件 | 有効フラグ | TRUE | - |
