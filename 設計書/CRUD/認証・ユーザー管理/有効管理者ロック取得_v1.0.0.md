| メソッド物理名 | lock_active_admin_ids |

### 処理概要

#### 【目的】
- 有効な管理者のIDを行ロックして取得する（最後の有効な管理者の判定を競合なく行うため）。

#### 【処理概略】
- ロール・有効フラグで絞り込み、`FOR UPDATE`でロックして内部IDの一覧を返却する。

## ○処理詳細

### 1. 有効管理者取得

- (1) app_userテーブルから取得する。

  ```sql
  SELECT id FROM app_user
  WHERE role = 'admin' AND is_active = TRUE
  ORDER BY id ASC
  FOR UPDATE;
  ```

  | 区分 | 項目名 | 設定値・設定元 | 備考 |
  |---|---|---|---|
  | 条件 | ロール | 管理者（`admin`） | 列挙値は設計書「テーブル定義（models）」を参照 |
  | 条件 | 有効フラグ | TRUE | - |

  - 並行する管理者更新処理と競合しないよう、内部IDの昇順でロックする（デッドロック防止）。
