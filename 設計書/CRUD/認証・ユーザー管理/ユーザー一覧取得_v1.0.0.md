## ○処理詳細

### 1. 総件数取得

- (1) 条件に合うレコード件数を取得する。

  ```sql
  SELECT COUNT(*) FROM app_user
  WHERE (:keyword IS NULL OR login_id ILIKE :like_pattern ESCAPE '\' OR name ILIKE :like_pattern ESCAPE '\')
    AND (:role IS NULL OR role = :role)
    AND (:is_active IS NULL OR is_active = :is_active);
  ```

  | 区分 | 項目名 | 設定値・設定元 | 備考 |
  |---|---|---|---|
  | 条件 | キーワード（部分一致パターン） | `%` ＋ 入力値．キーワード（`\`・`%`・`_`を`\`でエスケープ）＋ `%` | LIKEのワイルドカードを無効化する（SQLはバインドパラメーターで渡す） |
  | 条件 | ロール | 入力値．ロール | - |
  | 条件 | 有効フラグ | 入力値．有効フラグ | - |

### 2. 一覧取得

- (1) 同じ条件で、内部IDの昇順に取得する。

  ```sql
  SELECT * FROM app_user
  WHERE （1．(1)と同じ条件）
  ORDER BY id ASC
  LIMIT :page_size OFFSET :offset;
  ```

  | 区分 | 項目名 | 設定値・設定元 | 備考 |
  |---|---|---|---|
  | 条件 | オフセット | （入力値．ページ番号 − 1）× 入力値．1ページの件数 | - |
