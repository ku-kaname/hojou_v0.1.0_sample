| メソッド物理名 | create_user |

### 処理概要

#### 【目的】
- ユーザー情報をデータベースへ新規登録する（F16）。

#### 【処理概略】
- 入力値をもとにapp_userテーブルへレコードを登録し、`flush`する（`commit`は呼び出し元）。

## ○処理詳細

### 1. ユーザー情報登録

- (1) app_userテーブルへ登録する。

  ```sql
  INSERT INTO app_user (
    login_id, name, department, password_hash, role,
    is_active, must_change_password, token_generation,
    failed_login_count, locked_until, created_at, updated_at
  ) VALUES (
    :login_id, :name, :department, :password_hash, :role,
    TRUE, :must_change_password, 0,
    0, NULL, :now, :now
  );
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 登録内容 | ユーザーID | ○ | 入力値．ユーザーID | - |
  | 登録内容 | 氏名 | ○ | 入力値．氏名 | - |
  | 登録内容 | 所属 | ○ | 入力値．所属 | - |
  | 登録内容 | パスワードハッシュ | ○ | 入力値．ハッシュ済みパスワード | - |
  | 登録内容 | ロール | ○ | 入力値．ロール | - |
  | 登録内容 | 有効フラグ | ○ | TRUE | - |
  | 登録内容 | 初回パスワード変更要否 | ○ | 入力値．初回パスワード変更要否 | - |
  | 登録内容 | トークン世代 | ○ | 0 | - |
  | 登録内容 | 連続認証失敗回数 | ○ | 0 | - |
  | 登録内容 | ロック解除日時 | - | NULL | - |
  | 登録内容 | 作成日時・更新日時 | ○ | 入力値．現在日時 | - |

- (2) 例外処理

  | 条件 | 例外 | 備考 |
  |---|---|---|
  | ユーザーIDの一意制約に違反 | `IntegrityError` | 呼び出し元（ユーザー登録・初期管理者作成）が409または起動エラーとして扱う |
