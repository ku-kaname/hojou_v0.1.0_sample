### 処理概要

#### 【目的】
- 日次処理の自動取消の対象となる申請を、行ロックして取得する。

#### 【処理概略】
- 指定した状態の申請のうち、承認済みは返却予定日、申請中は開始日が今日より前の申請を、内部IDの昇順で`FOR UPDATE`により取得する。

## ○処理詳細

### 1. 対象の取得

- (1) loan_requestテーブルから、対象を行ロックして取得する。

  ```sql
  SELECT * FROM loan_request
  WHERE (:status = 'approved' AND status = 'approved' AND due_date < :today)
     OR (:status = 'requested' AND status = 'requested' AND start_date < :today)
  ORDER BY id ASC
  FOR UPDATE;
  ```

  | 区分 | 項目名 | 設定値・設定元 | 備考 |
  |---|---|---|---|
  | 条件 | 状態が承認済みの場合 | 状態＝`approved`かつ返却予定日が入力値．今日より前 | 返却予定日の翌日の日次処理時点で承認済みのまま＝ノーショー |
  | 条件 | 状態が申請中の場合 | 状態＝`requested`かつ開始日が入力値．今日より前 | 開始日の翌日の日次処理時点で承認・却下されないまま |
  | 並び順 | 内部ID | 昇順 | ロック取得順を固定し、他の処理とのデッドロックを避ける |

  - 行ロック取得時に状態が変わっていた（他の処理が先にコミットした）申請は、`FOR UPDATE`の再評価により対象から外れる。貸出処理と競合しても、先にコミットした側が有効となる。
  - 上記以外の状態が指定された場合は、対象なし（空リスト）となる。
