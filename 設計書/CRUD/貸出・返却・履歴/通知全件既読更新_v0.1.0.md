| メソッド論理名 | 通知全件既読更新 |
| メソッド物理名 | mark_all_notifications_read |

### 処理概要

#### 【目的】
- 宛先を指定して、未読の通知をすべて既読へ更新する（F08）。

#### 【処理概略】
- 宛先が一致し未読の通知の既読フラグを真にし、`flush`する（`commit`は呼び出し元が行う）。

## ○処理詳細

### 1. 通知の更新

- (1) notificationテーブルを更新する。

  ```sql
  UPDATE notification
  SET is_read = TRUE
  WHERE recipient_id = :recipient_id
    AND is_read = FALSE;
  ```

  | 区分 | 項目名 | 設定値・設定元 | 備考 |
  |---|---|---|---|
  | 条件 | 宛先（ユーザー内部ID） | 入力値．宛先内部ID | 他人の通知は対象外 |
  | 条件 | 既読フラグ | FALSE | - |
  | 更新 | 既読フラグ | TRUE | - |

  - 更新後、`flush`する。
