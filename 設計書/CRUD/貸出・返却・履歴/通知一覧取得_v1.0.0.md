### 処理概要

#### 【目的】
- 宛先を指定して、自分宛の通知（関連する備品の情報を含む）の一覧・総件数を取得する（F08）。

#### 【処理概略】
- 既読フラグで絞り込み、作成日時の新しい順にページ単位で取得する。

## ○処理詳細

### 1. 総件数取得

- (1) 条件に合う通知の件数を取得する。

  ```sql
  SELECT COUNT(*) FROM notification n
  WHERE n.recipient_id = :recipient_id
    AND (:is_read IS NULL OR n.is_read = :is_read);
  ```

  | 区分 | 項目名 | 設定値・設定元 | 備考 |
  |---|---|---|---|
  | 条件 | 宛先（ユーザー内部ID） | 入力値．宛先内部ID | - |
  | 条件 | 既読フラグ | 入力値．既読フラグ | NULLの場合は条件に含めない |

### 2. 一覧取得

- (1) 1．と同じ条件で、通知・貸出申請・備品を結合し、ページ単位に取得する。

  ```sql
  SELECT n.*, e.*
  FROM notification n
  JOIN loan_request lr ON lr.id = n.loan_request_id
  JOIN equipment e ON e.id = lr.equipment_id
  WHERE n.recipient_id = :recipient_id
    AND (:is_read IS NULL OR n.is_read = :is_read)
  ORDER BY n.created_at DESC, n.id DESC
  LIMIT :page_size OFFSET :offset;
  ```

  | 区分 | 項目名 | 設定値・設定元 | 備考 |
  |---|---|---|---|
  | 並び順 | 作成日時・内部ID | 降順 | 新しい通知が先頭。同時刻でも順序が安定するよう内部IDを併用する |
  | 取得位置 | オフセット | (入力値．ページ番号 − 1) × 入力値．1ページの件数 | - |
  | 取得件数 | 件数 | 入力値．1ページの件数 | - |

  - 備品は有効・無効を問わない（通知は無効化後も保持されるため）。
