#### 【目的】

## ○処理詳細

### 1. 件数取得

- (1) notificationテーブルから件数を取得する。

  ```sql
  SELECT COUNT(*) FROM notification
  WHERE recipient_id = :recipient_id
    AND is_read = FALSE;
  ```

  | 区分 | 項目名 | 設定値・設定元 | 備考 |
  |---|---|---|---|
  | 条件 | 宛先（ユーザー内部ID） | 入力値．宛先内部ID | - |
  | 条件 | 既読フラグ | FALSE | - |
