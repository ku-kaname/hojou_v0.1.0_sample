### 処理概要

#### 【目的】
- CSV出力用に、条件に合う貸出履歴（備品・借用者の情報を含む）を、件数上限つきで取得する（F17貸出履歴CSV出力）。

#### 【処理概略】
- 貸出履歴検索と同じ条件・並び順で、ページングせずに上限件数まで取得する。

## ○処理詳細

### 1. 貸出履歴取得

- (1) 貸出履歴検索と同じ条件で、貸出申請・備品・借用者を結合して取得する。

  ```sql
  SELECT lr.*, e.*, u.*
  FROM loan_request lr
  JOIN equipment e ON e.id = lr.equipment_id
  JOIN app_user u ON u.id = lr.requester_id
  WHERE lr.lent_at IS NOT NULL
    AND (:lent_from IS NULL OR lr.lent_at >= :lent_from)
    AND (:lent_to IS NULL OR lr.lent_at < :lent_to)
    AND (:equipment_id IS NULL OR lr.equipment_id = :equipment_id)
    AND (:requester_id IS NULL OR lr.requester_id = :requester_id)
  ORDER BY lr.lent_at DESC, lr.id DESC
  LIMIT :limit;
  ```

  | 区分 | 項目名 | 設定値・設定元 | 備考 |
  |---|---|---|---|
  | 条件 | 貸出日時 | 貸出日時が存在する（NULLでない） | 貸出履歴＝一度でも貸し出された申請（貸出中・返却済み）。却下・取消・貸出前の申請は含めない |
  | 条件 | 貸出日時開始 | 入力値．貸出日時開始以上 | NULLの場合は条件に含めない |
  | 条件 | 貸出日時終了 | 入力値．貸出日時終了より前 | NULLの場合は条件に含めない |
  | 条件 | 備品（内部ID） | 入力値．備品内部ID | NULLの場合は条件に含めない |
  | 条件 | 借用者（ユーザー内部ID） | 入力値．借用者内部ID | NULLの場合は条件に含めない |
  | 並び順 | 貸出日時・内部ID | 降順 | 貸出履歴検索と同じ |
  | 取得件数 | 件数 | 入力値．取得上限件数 | - |
