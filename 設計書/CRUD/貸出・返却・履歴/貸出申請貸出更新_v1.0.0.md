| メソッド物理名 | lend_loan_request |

### 処理概要

#### 【目的】
- 貸出申請を貸出中へ更新する（F10）。

#### 【処理概略】
- 状態・貸出処理した管理者・貸出日時を設定して`flush`する（`commit`は呼び出し元が行う）。

## ○処理詳細

### 1. 貸出申請の更新

- (1) 入力値．貸出申請情報の以下のフィールドを更新し、`flush`する。

  | 論理名 | 設定値 | 備考 |
  |---|---|---|
  | 状態 | `lent` | 設計書「テーブル定義（models）」の列挙値（申請状態）を参照 |
  | 貸出処理した管理者（ユーザー内部ID） | 入力値．貸出処理した管理者内部ID | - |
  | 貸出日時 | 入力値．現在日時 | - |

  - 同一備品に貸出中が既にある場合は、部分一意インデックス`uq_loan_request_equipment_lent`の違反（`IntegrityError`）が送出される。呼び出し元（サービス層）が捕捉して409へ変換する。
