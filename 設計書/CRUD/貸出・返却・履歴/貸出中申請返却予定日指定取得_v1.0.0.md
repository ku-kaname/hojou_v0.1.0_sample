### 処理概要

#### 【目的】
- 返却予定日が指定日の貸出中の申請を取得する（日次処理の返却期限通知）。

#### 【処理概略】
- loan_requestテーブルから、状態が貸出中かつ返却予定日が一致する申請を内部IDの昇順で取得する。

## ○処理詳細

### 1. 貸出中申請取得

- (1) loan_requestテーブルから取得する。

  ```sql
  SELECT * FROM loan_request
  WHERE status = 'lent'
    AND due_date = :due_date
  ORDER BY id ASC;
  ```

  | 区分 | 項目名 | 設定値・設定元 | 備考 |
  |---|---|---|---|
  | 条件 | 状態 | `lent` | 設計書「テーブル定義（models）」の列挙値（申請状態）を参照 |
  | 条件 | 返却予定日 | 入力値．返却予定日 | - |
