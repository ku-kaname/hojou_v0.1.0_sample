| メソッド物理名 | mark_notification_read |

### 処理概要

#### 【目的】
- 宛先を指定して、通知を1件既読へ更新する（F08）。

#### 【処理概略】
- 内部IDと宛先が一致する通知の既読フラグを真にし、`flush`する（`commit`は呼び出し元が行う）。他人の通知は更新できない。

## ○処理詳細

### 1. 通知の更新

- (1) notificationテーブルを更新する。

  ```sql
  UPDATE notification
  SET is_read = TRUE
  WHERE id = :notification_id
    AND recipient_id = :recipient_id;
  ```

  | 区分 | 項目名 | 設定値・設定元 | 備考 |
  |---|---|---|---|
  | 条件 | 内部ID | 入力値．通知内部ID | - |
  | 条件 | 宛先（ユーザー内部ID） | 入力値．宛先内部ID | 他人の通知は対象外 |
  | 更新 | 既読フラグ | TRUE | 既に既読でも更新対象に含め、冪等とする |

  - 更新後、`flush`する。
