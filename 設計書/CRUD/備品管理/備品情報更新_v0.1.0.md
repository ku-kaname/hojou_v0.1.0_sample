### メソッド名

| 項目 | 内容 |
|---|---|
| メソッド論理名 | 備品情報更新 |
| メソッド物理名 | update_equipment |

### 処理概要

#### 【目的】
- 備品の備品名・分類・説明・保管場所・有効フラグを更新する（資産番号は変更しない）。

#### 【処理概略】
- 取得済みの備品情報を更新する（`flush`のみ。コミットは呼び出し元）。

## ○処理詳細

### 1. 備品情報更新

- (1) equipmentテーブルを更新する。

  ```sql
  UPDATE equipment
  SET name = :name, category = :category, description = :description,
      location = :location, is_active = :is_active, updated_at = :now
  WHERE id = :equipment_id;
  ```

  | 区分 | 項目名 | 設定値・設定元 | 備考 |
  |---|---|---|---|
  | 更新内容 | 備品名 | 入力値．備品名 | - |
  | 更新内容 | 分類 | 入力値．分類 | - |
  | 更新内容 | 説明 | 入力値．説明 | - |
  | 更新内容 | 保管場所 | 入力値．保管場所 | - |
  | 更新内容 | 有効フラグ | 入力値．有効フラグ | - |
  | 更新内容 | 更新日時 | 入力値．現在日時 | - |
