## ○処理詳細

### 1. 備品一括登録

- (1) 入力値．備品登録内容一覧の各要素について、備品作成（→ CRUD「備品作成」）と同じ内容でequipmentテーブルへ登録する（1回のINSERTにまとめてよい）。

  | 区分 | 項目名 | 設定値・設定元 | 備考 |
  |---|---|---|---|
  | 登録内容 | 資産番号・備品名・分類・説明・保管場所 | 入力値．備品登録内容一覧の各要素 | - |
  | 登録内容 | 有効フラグ | TRUE | - |
  | 登録内容 | 作成日時・更新日時 | 入力値．現在日時 | - |

- (2) 例外処理

  | 条件 | 例外 | 備考 |
  |---|---|---|
  | 資産番号の一意制約に違反（事前確認後の同時登録） | `IntegrityError` | 呼び出し元（備品CSV一括登録）が409として扱う。1件でも失敗した場合は全件登録されない（呼び出し元がロールバックする） |
