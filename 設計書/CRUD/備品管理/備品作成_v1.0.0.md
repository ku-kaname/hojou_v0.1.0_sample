## ○処理詳細

### 1. 備品登録

- (1) equipmentテーブルへ登録する。

  ```sql
  INSERT INTO equipment (
    asset_number, name, category, description, location,
    is_active, created_at, updated_at
  ) VALUES (
    :asset_number, :name, :category, :description, :location,
    TRUE, :now, :now
  );
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 登録内容 | 資産番号 | ○ | 入力値．資産番号 | - |
  | 登録内容 | 備品名 | ○ | 入力値．備品名 | - |
  | 登録内容 | 分類 | ○ | 入力値．分類 | - |
  | 登録内容 | 説明 | ○ | 入力値．説明 | - |
  | 登録内容 | 保管場所 | ○ | 入力値．保管場所 | - |
  | 登録内容 | 有効フラグ | ○ | TRUE | - |
  | 登録内容 | 作成日時・更新日時 | ○ | 入力値．現在日時 | - |

- (2) 例外処理

  | 条件 | 例外 | 備考 |
  |---|---|---|
  | 資産番号の一意制約に違反 | `IntegrityError` | 呼び出し元（備品登録）が409として扱う |
