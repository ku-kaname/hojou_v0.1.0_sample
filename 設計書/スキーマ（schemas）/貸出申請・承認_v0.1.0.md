## 申請レスポンス
### クラス
|論理名|物理名|継承元|
|---|---|---|
| 申請レスポンス | LoanRequestResponse | BaseModel |

### 項目
|論理名|物理名|型|必須|最小値|最大値|最小桁|最大桁|備考|
|---|---|---|---|---|---|---|---|---|
| 内部ID | id | int | - | 1 | - | - | - | - |
| 備品内部ID | equipment_id | int | - | 1 | - | - | - | - |
| 備品資産番号 | equipment_asset_number | str | - | - | - | 1 | 32 | 無効化済みの備品でもそのまま表示する |
| 備品名 | equipment_name | str | - | - | - | 1 | 100 | - |
| 申請者内部ID | requester_id | int | - | 1 | - | - | - | - |
| 申請者氏名 | requester_name | str | - | - | - | 1 | 50 | 無効化済みのユーザーでもそのまま表示する |
| 申請者所属 | requester_department | str | - | - | - | 0 | 50 | - |
| 開始日 | start_date | date | - | - | - | - | - | - |
| 返却予定日 | due_date | date | - | - | - | - | - | - |
| 用途 | purpose | str | - | - | - | 1 | 200 | - |
| 状態 | status | str | - | - | - | - | - | 許容値は設計書「テーブル定義（models）」の列挙値（申請状態）を参照 |
| 理由 | reason | str | - | - | - | 0 | 200 | 却下・取消の理由。ない場合は空文字 |
| 返却時状態メモ | return_note | str | - | - | - | 0 | 200 | 返却前は空文字 |
| 申請日時 | requested_at | datetime | - | - | - | - | - | JSTオフセット付きISO 8601 |
| 承認却下日時 | decided_at | datetime \| None | - | - | - | - | - | 未処理はNULL |
| 貸出日時 | lent_at | datetime \| None | - | - | - | - | - | 未貸出はNULL |
| 返却日時 | returned_at | datetime \| None | - | - | - | - | - | 未返却はNULL |
| 取消日時 | canceled_at | datetime \| None | - | - | - | - | - | 未取消はNULL |
| 期限超過 | is_overdue | bool | - | - | - | - | - | 状態が貸出中かつ返却予定日が今日（JST）より前の場合に真（状態ではなく算出値） |
| 期限超過日数 | overdue_days | int | - | 0 | - | - | - | 期限超過の場合は今日 − 返却予定日、それ以外は0 |

---

- 承認・却下・貸出・返却・取消を行った管理者・者の内部IDは、いずれのレスポンススキーマにも含めない（画面で必要としないため）。
- 共通のスキーマ（エラー・ページング条件・ページング結果）は設計書「スキーマ（schemas）/共通」を参照。一覧のレスポンスは`Page[LoanRequestResponse]`とする。
