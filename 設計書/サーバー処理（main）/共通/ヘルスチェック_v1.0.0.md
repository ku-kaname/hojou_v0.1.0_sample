| メソッド物理名 | health_check |

### 処理概要

#### 【目的】
- Docker Composeの死活監視のため、バックエンドがDBへ接続できるかを返却する。

#### 【処理概略】
- DBへ単純な問い合わせ（`SELECT 1`）を行い、成否を返却する。認証は不要とし、内部情報（バージョン・接続先等）は返却しない。
