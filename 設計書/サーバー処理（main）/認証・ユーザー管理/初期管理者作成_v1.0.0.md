## ○メソッド概要

### クラス名

| 項目 | 内容 |
|---|---|
| クラス論理名 | エンドポイント層 |
| クラス物理名 | main |

### メソッド名

| 項目 | 内容 |
|---|---|
| メソッド論理名 | 初期管理者作成 |
| メソッド物理名 | lifespan（起動時処理） |
| サービス層メソッド論理名 | 初期管理者作成処理 |
| サービス層メソッド物理名 | `services.ensure_initial_admin` |

- 本書の「処理詳細」は、エンドポイント層（main）とサービス層（services）を通して記載する。エンドポイント層は入力の受付・検証済み値の引き渡し・HTTPレスポンス化のみを行い、業務処理はサービス層メソッドで行う（設計書「アーキテクチャ方針」参照）。

### 処理概要

#### 【目的】
- システム導入直後に管理者が1人もいない状態を解消するため、起動時に初期管理者を1人作成する。

#### 【処理概略】
- 起動時、有効な管理者が存在しない場合のみ、環境変数の情報で管理者を作成する。
- 既に管理者が存在する場合は何もしない（再起動しても重複作成しない）。

## ○処理詳細

### 1. 初期管理者作成（サービス層 `ensure_initial_admin`）

- (1) 現在日時を取得する（→ サービス層 `get_now`）。

- (2) 有効な管理者IDを取得する（→ CRUD「有効管理者ID一覧取得」）。

  | 条件 | 動作 |
  |---|---|
  | 1件以上ある | 何もせず終了する（戻り値なし） |
  | 0件 | 次の処理へ |

- (3) 環境変数を検証する。

  | 条件 | 例外 | エラー内容 |
  |---|---|---|
  | 環境変数のいずれかが未設定・空、またはユーザーID・パスワードの形式・桁数が不正 | RuntimeError | "初期管理者の環境変数が未設定または不正です"（パスワードの値は含めない） |

  - 例外はアプリケーションの起動を中断させる（設定不備のまま運用に入らないため）。

- (4) ユーザーIDの重複を確認する（→ CRUD「ユーザーID指定取得」。行ロック要否=False）。

  | 条件 | 動作 |
  |---|---|
  | 取得できた（同一IDが無効化済み・一般ロールで存在） | RuntimeError "初期管理者のユーザーIDが既存ユーザーと重複しています" を送出する |

- (5) パスワードをハッシュ化する（→ 認証・認可 `hash_password`）。

- (6) 管理者を作成する（→ CRUD「ユーザー作成」）。

  | 引数 | 設定値 |
  |---|---|
  | ユーザーID | 環境変数．初期管理者ユーザーID |
  | 氏名 | "初期管理者" |
  | 所属 | ""（空文字） |
  | ハッシュ済みパスワード | (5)のハッシュ |
  | ロール | 管理者（設計書「テーブル定義（models）」の列挙値（ロール）を参照） |
  | 初回パスワード変更要否 | True |
  | 現在日時 | (1)の現在日時 |

- (7) コミットする。

  | 条件 | 動作 |
  |---|---|
  | 複数プロセスの同時起動で一意制約違反（`IntegrityError`） | ロールバックし、再度(2)を実行して管理者が存在すれば正常終了する |

- (8) 作成した旨をサーバーログに記録する（ユーザーIDのみ。パスワードは記録しない）。
