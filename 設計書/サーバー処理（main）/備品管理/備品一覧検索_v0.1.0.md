### 処理概要

#### 【目的】
- 備品を分類・キーワード・貸出状況で検索し、現在の貸出状況とともに一覧表示する。

#### 【処理概略】
- 絞り込み条件でページ単位に検索し、貸出状況を算出して返却する。
- 無効化済みの備品を含める指定は管理者のみ可能とする。

### 備品レスポンス（`EquipmentResponse`）

貸出中の申請は、各要素の「貸出中の申請」（2．(2)の備品一覧の各要素の2番目）、借用者氏名は3番目を指す。今日は2．(1)の値。

| 論理名 | 物理名 | 型 | 設定値 | 備考 |
|---|---|---|---|---|
| 内部ID | `id` | `int` | 備品．内部ID | - |
| 資産番号 | `asset_number` | `str` | 備品．資産番号 | - |
| 備品名 | `name` | `str` | 備品．備品名 | - |
| 分類 | `category` | `str` | 備品．分類 | - |
| 説明 | `description` | `str` | 備品．説明 | - |
| 保管場所 | `location` | `str` | 備品．保管場所 | - |
| 有効フラグ | `is_active` | `bool` | 備品．有効フラグ | - |
| 貸出状況 | `availability` | `str` | 貸出中の申請がある場合`lent`、ない場合`available` | 貸出状況は備品の貸出中の申請の有無から算出する（テーブルの列ではない） |
| 現在の返却予定日 | `current_due_date` | `date \| None` | 貸出中の申請．返却予定日 | 貸出中でない場合はNULL |
