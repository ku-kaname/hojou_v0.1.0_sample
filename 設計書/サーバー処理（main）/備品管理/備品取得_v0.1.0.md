### 処理概要

#### 【目的】
- 備品1件の詳細と現在の貸出状況を取得する（備品詳細画面用）。

#### 【処理概略】
- 備品を取得し、無効化済みは管理者以外には存在しないものとして扱う。

## ○処理詳細

### 1. 備品の取得（サービス層 `get_equipment_detail`）

- (1) 備品を内部IDで取得する。

  **呼出先**

  | 項目 | 論理名 | 物理名 |
  |---|---|---|
  | クラス | データアクセス層 | crud |
  | メソッド | 備品内部ID指定取得 | get_equipment_by_id |

  **引数**

  | 引数 | 型 | 必須 | 設定値 | 備考 |
  |---|---|:---:|---|---|
  | データベース | `Session` | ○ | 入力値．データベース | - |
  | 備品内部ID | `int` | ○ | 入力値．備品内部ID | - |
  | 行ロック要否 | `bool` | ○ | False | - |

- (2) 例外処理

  | 条件 | 例外 | ステータスコード | エラー内容 |
  |---|---|---:|---|
  | (1)で取得できない | HTTPException | 404 | "備品が見つかりません" |
  | (1)の備品の有効フラグが偽、かつ入力値．認証済みユーザー．ロールが管理者でない | HTTPException | 404 | "備品が見つかりません"（無効化済みの存在を一般ユーザーに知らせない） |

### 2. 現在の貸出状況の取得

- (1) 今日の日付（JST）を取得する（→ サービス層 `get_today`）。

- (2) 貸出中の申請を取得する（→ CRUD「貸出中申請取得」。備品内部ID=入力値．備品内部ID）。

### 3. 戻り値を設定

## ○戻り値

| 論理名 | 物理名 | 型 | 設定値 | 備考 |
|---|---|---|---|---|
| 備品レスポンス | `equipment_response` | `EquipmentResponse` | 1．(1)の備品、2．(2)の貸出中の申請と借用者氏名、2．(1)の今日から変換 | - |

### 備品レスポンス（`EquipmentResponse`）

貸出中の申請は2．(2)の1番目、借用者氏名は2番目を指す。

| 論理名 | 物理名 | 型 | 設定値 | 備考 |
|---|---|---|---|---|
| 内部ID | `id` | `int` | 備品．内部ID | - |
| 資産番号 | `asset_number` | `str` | 備品．資産番号 | - |
| 備品名 | `name` | `str` | 備品．備品名 | - |
| 分類 | `category` | `str` | 備品．分類 | - |
| 説明 | `description` | `str` | 備品．説明 | - |
| 保管場所 | `location` | `str` | 備品．保管場所 | - |
| 有効フラグ | `is_active` | `bool` | 備品．有効フラグ | - |
| 貸出状況 | `availability` | `str` | 貸出中の申請がある場合`lent`、ない場合`available` | 貸出状況は備品の貸出中の申請の有無から算出する（テーブルの列ではない） |
| 現在の返却予定日 | `current_due_date` | `date \| None` | 貸出中の申請．返却予定日 | 貸出中でない場合はNULL |
| 期限超過 | `is_overdue` | `bool` | 貸出中かつ返却予定日 ＜ 今日（JST）の場合True | - |
| 現在の借用者氏名 | `current_borrower_name` | `str \| None` | 呼び出したユーザーが管理者かつ貸出中の場合のみ借用者氏名、それ以外はNULL | 一般ユーザーには借用者名を返さない（要件定義書「機能要件」アクセス制御表F04） |
| 作成日時 | `created_at` | `datetime` | 備品．作成日時 | - |
| 更新日時 | `updated_at` | `datetime` | 備品．更新日時 | - |

- 正常時のHTTPステータスコードは200。
