### 処理概要

#### 【目的】
- 管理者が、過去の貸出（貸出中・返却済み）を、期間・備品・借用者で絞り込んで確認する。遅延した貸出・返却を遅延日数で確認できる。

#### 【処理概略】
- 貸出日の範囲を検証・変換し、条件に合う貸出履歴を貸出日時の新しい順でページ単位に返却する。

## ○処理詳細

### 1. 貸出履歴検索（サービス層 `search_loan_history`）

- (1) 今日の日付（JST）を取得する（→ サービス層 `get_today`）。

- (2) 貸出日の範囲を検証し、DB検索用の日時範囲へ変換する。

  | 条件 | 例外 | ステータスコード | エラー内容 |
  |---|---|---:|---|
  | 入力値．貸出履歴条件．貸出日終了が、貸出日開始より前（両方指定時） | HTTPException | 400 | "貸出日終了は貸出日開始以降を指定してください" |

  | 論理名 | 設定値 | 備考 |
  |---|---|---|
  | 貸出日時開始 | 入力値．貸出日開始のJST 0時0分をUTCへ変換した日時 | 貸出日開始がNULLの場合はNULL |
  | 貸出日時終了 | 入力値．貸出日終了の翌日のJST 0時0分をUTCへ変換した日時 | 貸出日終了がNULLの場合はNULL。終了日の当日を含めるため、翌日0時「より前」で判定する |

- (3) 貸出履歴の一覧・総件数を取得する。

  **呼出先**

  | 項目 | 論理名 | 物理名 |
  |---|---|---|
  | クラス | データアクセス層 | crud |
  | メソッド | 貸出履歴検索 | search_loan_history |

  **引数**

  | 引数 | 型 | 必須 | 設定値 | 備考 |
  |---|---|:---:|---|---|
  | データベース | `Session` | ○ | 入力値．データベース | - |
  | 貸出日時開始 | `datetime \| None` | - | (2)の貸出日時開始 | - |
  | 貸出日時終了 | `datetime \| None` | - | (2)の貸出日時終了 | - |
  | 備品内部ID | `int \| None` | - | 入力値．貸出履歴クエリ．備品内部ID | - |
  | 借用者内部ID | `int \| None` | - | 入力値．貸出履歴クエリ．借用者内部ID | - |
  | ページ番号 | `int` | ○ | 入力値．貸出履歴クエリ．ページ番号（省略時1） | - |
  | 1ページの件数 | `int` | ○ | 入力値．貸出履歴クエリ．1ページの件数（省略時20） | - |

  - 存在しない備品・借用者を指定した場合も、エラーとせず該当なし（空配列）とする。

## ○戻り値

| 論理名 | 物理名 | 型 | 設定値 | 備考 |
|---|---|---|---|---|
| 貸出履歴ページ | `loan_history_page` | `Page[LoanHistoryResponse]` | 1．(3)の明細一覧を`LoanHistoryResponse`へ変換、総件数、ページ番号、1ページの件数 | 明細は貸出日時の降順。該当なしは空配列 |

- 遅延日数は、貸出中は「1．(1)の今日 − 返却予定日」、返却済みは「返却日時をJSTへ変換した日付 − 返却予定日」とし、いずれも負の場合は0とする。
- 項目は設計書「スキーマ（schemas）/共通」のページング結果、および設計書「スキーマ（schemas）/貸出・返却・履歴」の貸出履歴レスポンスを参照。
- 正常時のHTTPステータスコードは200。
