## 一般利用者が行える操作
| No | 機能 | 説明 |
|---|---|---|
| F01 | ログイン・ログアウト | ユーザーID・パスワードで認証し、ログイン状態を開始・終了する |
| F02 | パスワード変更 | 自分のパスワードを変更する |
| F03 | 備品検索・一覧表示 | 備品を分類・キーワード・状態で検索し一覧表示する。備品ごとの現在の貸出状況（貸出可・貸出中・返却予定日）も確認する |
| F04 | 備品の予約状況確認 | 備品ごとに、承認済み・貸出中の期間を確認し、空き期間を把握する |
| F05 | 貸出申請 | 備品と貸出期間（開始日・返却予定日）・用途を指定して貸出を申請する。将来日の予約を含む |
| F06 | 申請取消 | 自分の「申請中」または「承認済み」の申請を、貸出前であれば取り消す |
| F07 | 自分の申請・貸出状況確認 | 自分の申請の状態（申請中・承認済み・貸出中・返却済み・却下・取消）と履歴を確認する |
| F08 | 通知確認 | アプリ内通知（承認・却下・取消の結果、返却期限が近い/超過している貸出。管理者は新規申請の件数も表示）を確認する。メール等の外部通知は行わない |

## 管理者が行える操作
管理者は、一般利用者が行える操作（F01〜F08）もすべて行える。以下は管理者のみが行える操作。

| No | 機能 | 説明 |
|---|---|---|
| F09 | 申請承認・却下 | 申請中の申請を確認し、承認または却下（理由必須）する。承認時に期間の重複を再確認する |
| F10 | 貸出処理 | 承認済みの申請について、備品を渡したことを記録する（貸出日時を記録） |
| F11 | 返却処理 | 貸出中の備品について、返却を受けたことを記録する（返却日時・状態メモ） |
| F12 | 申請の管理者取消 | 承認済みの申請を管理者が取り消す（理由必須。備品故障等） |
| F13 | 期限超過一覧確認 | 返却予定日を過ぎた貸出の一覧を確認する |
| F14 | 備品登録・編集・無効化 | 備品を1点ずつ登録・編集・無効化（論理削除）する。無効化済みの備品の再有効化も行える |
| F15 | 備品CSV一括登録 | CSVファイルから備品を一括登録する |
| F16 | ユーザー登録・編集・無効化 | 社員アカウントを登録・編集・無効化する。ロール（一般/管理者）の設定、パスワード初期化、無効化済みユーザーの再有効化を含む |
| F17 | 貸出履歴閲覧・CSV出力 | 全社員の貸出履歴を検索・閲覧し、CSV出力する |

## 管理者ユーザーの作成・管理
- 初回の管理者アカウントは、システム構築時に環境変数で指定した値で起動時に自動作成する（自己登録の画面は設けない）。
- 以降の管理者アカウントは、既存の管理者がF16で作成・ロール変更する。
- 最後の有効な管理者を無効化・一般ロールへの変更はできない（業務ルール参照）。
